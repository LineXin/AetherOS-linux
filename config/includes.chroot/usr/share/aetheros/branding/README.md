# AetherOS wallpapers

- `aetheros-wallpaper-mountain.svg` — cinematic mountain sunset edition
- `aetheros-wallpaper-abstract.svg` — minimal graphite and orange edition

Both are resolution-independent SVG assets (2560×1440 viewBox) and work with XFCE and KDE Plasma. The login-session autostart helper applies the mountain edition by default. The images are also copied to `/usr/share/backgrounds/`.
